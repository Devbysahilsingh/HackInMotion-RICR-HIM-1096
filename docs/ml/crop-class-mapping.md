# Unified Class Map (~34 classes + cotton's 8 if OD-1 passes)

Codes are language-neutral (`CROP_CONDITION`); i18n names in shared/i18n; registry lists per-crop `mlClassCodes`.

> **Status after the P0-5 audit (2026-08-12): the crop lists below are not reconciled with the data, deliberately.** The audit measured what actually existed at that date — 36 codes with data, per-class counts in `docs/ml/dataset-audit.md` — and found three mismatches with the lists below: the RICE section still describes the **rejected** Paddy Doctor set (only 4 rice codes had data, and `RICE_NORMAL` was not among them — P0-5b subsequently acquired it); COTTON has **7** classes, not 8; and the chilli `?` codes are all present. Merge/drop/rename decisions are the team's and are listed in the audit report; the lists below are updated when they are made, not before.
>
> **Status after P3 (2026-08-13): the class contract itself is now settled and materialised, even though this file's lists are not.** The authoritative list is the **35 classes** in `datasets/manifest.json`, and it is now carried in two places derived from it, not hand-maintained:
>
> - `ml-service/model/model-manifest.json` — generated by `scripts/generate_model_manifest.py` (`--check` fails on drift; `ml-service/tests/test_manifest.py` fails on drift), including `healthyClasses` and the per-crop groupings;
> - `cropRegistry.mlClassCodes` — composed by the registry seed from the same manifest, so a crop can never claim ML support for a class with no data.
>
> **Every one of the 35 classes now has a registry KB entry** (symptoms / inspect / next steps / prevention, with `sourceRefs`) — the composed registry holds exactly 35 disease codes and the manifest's 35 classes map onto them with none missing. The "no diagnosis without guidance" gate below is therefore **met in English**.
>
> **It is NOT met in Hindi: disease-KB Hindi coverage is 0 of 408 strings** (`backend/tests/i18n/disease-keys.test.js` prints the count on every run). Rule 8 forbids translating agronomic terms without human verification, so the gap is recorded rather than filled; a farmer using the Hindi UI would see English disease guidance today. This blocks the demo claim, not the model.
>
> Note also that class order in `model-manifest.json` is a **placeholder** (sorted ascending by code). The trained exporter's output index order is authoritative and must overwrite it — a silent mismatch mislabels every prediction while every health check stays green.
