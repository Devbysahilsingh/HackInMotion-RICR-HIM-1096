# Intelligence APIs (fertilizer · crop-recommendation · community · yield · voice)

| Endpoint | Auth · RL | Spec |
|---|---|---|
| GET `/crops/:id/fertilizer-guidance` | Auth | → current-stage card + full schedule + deficiency symptoms + sources + disclaimer. Pure registry read. Errors: 404. P1. |
| POST `/crop-recommendation` | Auth · 20/day | Req `{farmId, season, preference?}` → ranked crops + reasons + cautions + sources (docs/crop-recommendation/engine.md). Errors: 404, 422. P1. |
| GET `/community/alerts?district=&state=` | Auth | Active advisories for user's farm districts (auto from profile if params omitted; a farmer with no farms gets `[]`). **Shipped payload:** `{alerts: [{district, state, cropCode, diseaseCode, reportCount, level, windowStart, windowEnd}]}`. Adds `state` (district names repeat across Indian states, and the aggregation groups on (state, district) for that reason) and `windowStart` (a window is not an end date). Deliberately **omits** `distinctFarmers` — equal to `reportCount` by construction, so publishing it would only create a second counter that could drift — and omits `_id`/timestamps (nothing addresses an alert individually). Authenticated but unscoped (AU-6): the documents are district counts owned by nobody. **No write API** — the 6-hourly job is the only writer, which is what makes the ≥3-farmer threshold ungameable from outside. Zero reporter data by construction. P2. |
| GET `/crops/:id/yield-estimate` | — | **NOT MOUNTED. Returns 404.** Corrected 2026-08-14: this row previously said "returns 501 NOT_IMPLEMENTED", but no such route is registered in `backend/src/routes/`, so the server answers 404 like any unknown path. The `yieldEstimates` schema and the design in `docs/yield/yield-estimation.md` are real; the endpoint is not. **Blocked on data, not on code** — the estimator needs `Y_hist`, a district×season×crop yield lookup, and `datasets/lookup/` (named in `datasets/README.md`) does not exist. Planned response when built: `{estimateRange:{low,high,unit:'quintal'}, basis:{districtAvgYield, year}, adjustments:[{factorKey, multiplier}], disclaimerKey}`. |
| POST `/voice/transcribe` | — | **NOT MOUNTED. Returns 404.** Was specified as P2-optional (multipart audio ≤60s → Groq Whisper proxy). It was never built: web speech-to-text uses the browser's own Web Speech API and mobile ships text-to-speech only, so no client needs this proxy. Listed here for provenance, not as an available contract. |

Community aggregation job (6h): cropHealthLogs where sharedToCommunity ∧ source∈{ml,gemini} ∧ confidence≥τ, grouped district+cropCode+diseaseCode over trailing 7d; distinctFarmers≥3 → upsert communityAlerts + fan-out INFO/HIGH recommendations (HIGH at ≥8 reports) to consenting users with matching crop+district. Single-report never alerts (panic prevention). Duplicate control: one counted report per farmer+crop+disease+window.
