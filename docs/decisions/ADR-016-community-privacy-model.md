# ADR-016 · Community alerts privacy model
**Status:** Accepted · 2026-08-12
**Decision:** opt-in consent; district-level aggregation only; ≥3 distinct farmers threshold; alert documents structurally contain no PII; ML/Gemini-confirmed reports only; single report never surfaces.
**Alternatives:** map pins / radius queries (deanonymization risk), all-reports feed (panic + noise), verified-officer moderation (no capacity in 72h — future).
**Trade-offs:** district granularity is coarse (adjacent-district blindness — stated future work) — privacy wins the tie.
