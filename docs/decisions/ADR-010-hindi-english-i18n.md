# ADR-010 · Hindi+English core; shared i18n tree; human-verified terminology
**Status:** Accepted · 2026-08-12
**Decision:** full parity via i18next both surfaces; canonical resources in shared/i18n; language-neutral codes/keys in DB and APIs; curated agri terminology table with mandatory human verification; no machine-translated agronomic instructions.
**Alternatives:** English+partial Hindi (fails core requirement); runtime MT (quality/safety risk on ag guidance).
**Trade-offs:** translation authoring effort budgeted in roadmap; Gemini free-text findings remain English-labeled (disclosed limitation, P3).
