# Dependency Security

- **Policy:** every dependency must earn its place (functionality we'd otherwise write worse); prefer stdlib/platform; no abandoned packages (last publish >2y = justify); lockfiles committed (package-lock.json, requirements pinned).
- **Audit gates:** `npm audit --omit=dev` (backend, web, mobile) + `pip-audit` (ml-service) — run before every deploy and in Day-3 checklist; high/critical → upgrade or replace before ship (documented exception process requires team sign-off, none expected).
- **Supply-chain hygiene:** exact-version pins in ml-service requirements; no postinstall-script packages added casually; new deps reviewed in PR (named in description).
- **Planned dependency set (locked at planning to prevent drift):** backend: express, mongoose, zod, jsonwebtoken, bcrypt, helmet, cors, express-rate-limit, multer, sharp, file-type, pino(+http), node-cron, cloudinary, express-mongo-sanitize, @google/genai. web: react, react-router, @tanstack/react-query, axios, i18next(+react, +languagedetector), tailwindcss, recharts (charts), vite. mobile: expo SDK, expo-camera, expo-image-picker, expo-image-manipulator, expo-location, expo-secure-store, expo-speech, @react-navigation, @tanstack/react-query, @react-native-async-storage/async-storage, axios, i18next. ml: fastapi, uvicorn, onnxruntime, pillow, pydantic, python-multipart. training: torch, torchvision, albumentations, onnx, scikit-learn, matplotlib. Additions beyond this list require a stated reason in the PR.
